# SPR-008 — Autorização (RBAC) e HTTP Pipeline

## Objetivo

Fortalecer a fundação arquitetural do Content-OS com três entregas independentes:

1. Autorização por papel (RBAC) sobre a autenticação já entregue na SPR-007.
2. Padronização do HTTP Pipeline (validação, tratamento de erro e formato de resposta).
3. Versionamento de API e consolidação da documentação.

Esta sprint **não** implementa novas funcionalidades de negócio — fortalece a fundação sobre a
qual funcionalidades futuras serão construídas.

Decisões de arquitetura: `ADR-004-rbac-strategy.md`, `ADR-003-validation-strategy.md`,
`ADR-005-api-versioning-strategy.md`, `ADR-007-http-response-standardization.md`.
